**Polimorfismo passivo**: si basa principalmente sul metodo del duck typing (basta che l'oggetto possieda i metodi corretti per poterlo utilizzare).

In Python non è necessario che un oggetto appartenga a una determinata gerarchia di classi o implementi un'interfaccia esplicita.



**Duck typing**: una logica che usa il polimorfismo di Python. Per noi è passivo, ma possiamo sfruttarlo tramite i metodi polimorfici.



**len()** > funziona con vari metodi purché implementino il metodo speciale **\_\_len\_\_()**.



**main**: nome del file momentaneo che stiamo facendo girare.
